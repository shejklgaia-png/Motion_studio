# Motion Studio（開発試作版 v1.1）

Android縦画面を第一に考えた、**日本語UIのモーション・IK・制約・接触検証一体型エディター**です。Godot 4.xで制作し、無料・オフライン利用を前提としています。PCのGodotエディターでも開けます。

> **状態:** 機能検証用の試作版です。GitHub ActionsのGodot 4.6自動テストとAndroid APKビルドを行っていますが、Android実機のタッチ操作は未検証です。ロードマップは段階的に実装しています。

## 現時点で用意した機能

- 3Dサンプル四脚モデル、部位タップ選択、カメラ回転・ズーム
- タイムライン再生、1フレーム送り、数値による部位ごとの位置・回転・スケールのキーフレーム編集
- IK（CCD・FABRIK・**解析2ボーンIK**）と目標位置・強度・適用区間。2ボーンではポールベクトルで膝の方向を調整できます。
- 位置・回転・スケールの軸別上限/下限、適用区間、強度
- テストオブジェクト（箱・球・カプセル）の配置と物理接触センサーによる検出
- IK目標・接地固定の残差、共有関節を使うIKの警告、サンプル足先の床からの浮き／めり込み診断
- 足先IKの床・空間固定、テスト物体相対固定、固定時間・摩擦と線形滑走速度、黄色い3D接地目標マーカー
- 自動保存、Undo/Redo、専用JSON形式の保存・復元
- Blockbench 4.x/5.x `.bbmodel`：グループ階層・ピボット・cube/自由形状mesh・UV・埋め込みPNGテクスチャの読み込み
- Blockbench内に保存された複数アニメーションの選択・再生・キーフレーム編集（位置／回転／スケール）
- glTF/GLBシーンの読み込み
- IK・制約を各フレームで焼き込んだ Godot Animation `.tres` 出力
- IK/FKを全関節の編集可能なキーフレームへ変換（30/60fps）、IK自動停止、元モーション復元、差分診断

## 起動方法

Godot 4.6（Standard）で本フォルダの `project.godot` を開き、メインシーンを実行してください。Android上ではGodot Android Editorでプロジェクトを開いて確認できます。実機配布用APKの生成にはAndroid出力テンプレートなどが必要です。

## .bbmodelファイルの読み込み（Android）
1. アプリ上部の「BB読込」を押します。
2. Androidのファイル選択画面で、端末に保存した `.bbmodel` を選択します。
3. 画面中央にモデルが表示されたら、「読込モーション」で保存済みアニメーションを選びます。
4. 「▶ 再生」でモーションを確認し、部位を選んで編集します。

読み込み後、簡単なBlockbench 5形式のモデルとアニメーションについて、GitHub ActionsのGodot 4.6テストを実施しています。すべてのBlockbenchプラグイン独自要素に対応しているわけではありません。

## 地表追従IK（なぎ払いのめり込み補正）

Blockbenchで作ったなぎ払いの**元のX/Z軌道（曲線）を維持**したまま、下肢・足先メッシュの最下部が床に接するよう、各フレームでIK目標の高さだけ補正します。従来の「床に固定／一定速度で滑走」と異なり、横方向の動きを作り直す必要はありません。

1. 「IK設定」で対象脚のチェーンを選択し、始点・中間・末端の関節を指定します。通常は「2ボーン」が適しています。
2. 「**元のなぎ払い軌道に沿って地表をなぞる**」をONにします。IKも自動的に有効になります。
3. 青い「IK適用」バーの両端をドラッグし、地面を這う区間を指定します。
4. 「**下肢のメッシュもめり込み判定**」は必要に応じてON/OFF。床の高さ（既定0m）と接地余裕（既定0.005m）を調整します。
5. モーションを再生して関節が自然な範囲で曲がるか確認し、問題なければ「IK/FKをキーフレーム化」で30/60fpsの通常アニメーションとして保存します。

**補足：** 床は水平な平面です。脚が届かない位置や関節制約との矛盾がある場合、すべてのめり込みを必ず防ぐものではなく「診断」に接地誤差が表示されます。地表追従をONにしたチェーンでは、同じ脚に設定された従来の「床に固定／滑走」より地表追従が優先します。プロジェクト保存・復元とUndo/Redoに対応しています。

## IK/FKベイク（Godotでの軽量な再生）

1. 「IK」で目標位置・計算方法を設定し、モーションの動作を確認します。
2. 「詳細機能 ▾」→「ベイク」を開きます。足先を固定・滑走させる場合は「詳細機能 ▾」→「接触」で設定します。
3. 記録精度を30fps／60fpsから選び、「IK/FKをキーフレーム化」を押します。
4. FK・IK・制約の合成結果を全関節のローカル位置・回転・拡縮に変換します。変換後は現在のIKと制約を無効化し、キーフレームのみで再生します。
5. 「ベイク前に戻す」で元のキーフレーム・IK・制約設定を復元できます。保存したMotion Studioプロジェクトには元データのバックアップも含まれます。
6. 「ファイル ▾」→「Godotアニメーションを書き出す」で `.tres` を出力できます。

**注意:** フラットな床など、固定条件で事前計算できる動作に適します。ベイク後のIK・接地固定は停止しますが、物理衝突や移動する障害物の未来の動きを自動推測してベイクする機能ではありません。IKの目標・制約の矛盾は変換前に修正してください。ベイク時に中間フレームを比較し、位置・回転の最大誤差を表示します。サンプル間の完全一致は保証されません。

大量のキーフレームでスマホが操作不能にならないよう、時間バー下のショートカットは一部だけを表示します。全フレームのデータは保持され、スライダーとフレーム送りで編集できます。

## はじめての操作（スマートフォン）

1. 画面上の **「ファイル ▾」→「モデルを読み込む」** からBlockbenchの `.bbmodel` を選びます。最初の四脚サンプルでも試せます。
2. 3D表示の下にある **「① モーション選択」** から再生したいアニメーションを選びます。
3. **「② 動かす部位」** または上部の **「部位・階層」** から関節を選びます。
4. 上の **「▶ 再生」** で動きを確認し、黄色い◆や青い再生ヘッドで編集する時間を選びます。
5. 3D画面右下の **「回転」** または **「移動」** を選び、色付きハンドルを指で動かします。変更は現在の時間にキーフレームとして保存されます。
6. 右下の **「視点移動」** でカメラを平行移動します。2本指ピンチはカメラのズームであり、モデルの拡縮ではありません。

### IKの次段階（今回実装）

- **「IK設定」→「計算方法」→「2ボーン」** を選ぶと、解析的な2関節IKを使用します。
- **「膝方向（ワールド方向）」** のX・Y・Zで曲がる側を指定できます。例えばZを+1と-1で切り替えると膝の折れる側が反転します。
- **3Dプレビュー上のIK目標** にX/Y/Z軸の矢印が出ます。矢印をドラッグして、目標点を指で3次元方向へ移動できます。元の緑の球をドラッグする床平面操作も残しています。
- IKの設定とポールベクトルはプロジェクト保存・復元に含まれ、IK/FKベイクでは完成姿勢をキーフレームへ変換できます。

### v1.0：指での編集を改善

- **タイムラインの◆をタップ**すると、そのキーフレームに移動します。◆を左右に12px以上ドラッグすると時刻変更のプレビューになり、指を離すとfpsのグリッドにスナップしてキーが移動します。先頭・末尾、またはほかのキーに重なる移動は安全のため拒否します。
- **重要：このバージョンのキーは全身の姿勢を持つフレームです。** 画面では回転・位置・拡縮の3列に表示していますが、キーの時刻を移動するとその時刻の全身フレームが移動します。部位・チャンネルごとに独立したキーフレーム編集は今後の課題です。
- 上部の**↶／↷**で直前の編集の取り消し・やり直しができます。削除できるキーがない時は何も消さず理由を表示します。
- 3D画面の**「全体表示」**でモデルを画面内に収め直せます。回転リング・移動矢印は太くなり、指で押せる許容範囲を拡大しました。
- タイムラインを手で操作すると再生は自動停止するため、編集直後に動き続けません。2本指ピンチでのカメラズーム、IK・FK、接触、制約、ベイク、Godot書き出しは従来どおり残っています。

### v1.1：ロードマップ「足先固定・滑走」を実装

- **「詳細機能 ▾」→「接触」** から対象のIKチェーンを選び、「床に固定」「空間に固定」「物体に固定」を押すと、その時点の足先を固定目標として記録します。
- 「床に固定」は高さ0m、空間固定は3Dの現在位置、物体固定は選択したテスト物体のローカル位置を使用します。テスト物体の移動・回転・拡縮に追従します。**黄色い球**で現在の固定目標をプレビューします。
- **固定強度・開始と終了時間・摩擦（0〜1）・滑走速度（m/s）** を設定できます。摩擦が1なら滑走なし、0なら指定速度で滑走します。滑走位置は再生時刻から毎回計算されるため、時間を戻して再生しても同じ結果になります。床固定ではY方向の滑走は適用しません。
- 複数のIKチェーンで同じ関節を共有する場合は、**固定順の3回反復**で簡易的に補正し、診断画面に共有警告を表示します。これは全身IKの最適解や力学的な摩擦・衝突の完全再現ではありません。
- ベイクすると、接地固定とIKで完成した姿勢を30/60fpsのFKキーフレームへ変換し、ゲーム中はIK・接地固定を停止できます。元の接触設定とIKは「ベイク前に戻す」で復元でき、プロジェクトにも保存されます。

**未実装の範囲:** メッシュ上の面・線・頂点の選択、物理ベースの摩擦計算、動的な地形の追従、複数IKの全身最適化、接触力の計測などは引き続きロードマップ対象です。

### ワークスペース

- **主な3モード：** 「部位・階層」「動きを編集」「IK設定」
- **「詳細機能 ▾」：** 制約・接触・診断・ベイク。これらの機能は削除せず引き続き使えます。
- **タイムライン：** 時間のスライダー、回転／位置／拡縮の3チャンネル、キー追加・削除、フレーム送り。「すべてのキーを見る」で従来のキー一覧を開けます。
- **編集パネル：** 選んだモードの項目を表示。パネルを閉じてもモーション・部位の選択欄は残ります。
- **「操作 ▾」：** Undo／Redo／使い方。**「ファイル ▾」** に読み込み・保存・Godot出力をまとめています。

Blockbenchのワークスペース構成を参考にしていますが、Android縦画面の操作に合わせてパネルをまとめています。モデルの頂点編集・ペイントなど、元々未実装の機能が今回追加されたわけではありません。

## 操作方法

1. 起動直後の四脚モデルで「モーション」から編集部位とキーフレームを選びます。
2. 「IK」でチェーンと目標位置を指定し、有効化するとプレビューへ反映されます。
3. 「制約」で移動・回転・伸縮の限界を指定できます。
4. 「接触」で障害物を配置し、接地状態を確認します。
5. 「診断」で原本姿勢とIK計算後を比較し、「書き出し」で保存／出力します。

### 注意事項

- Blockbench 5形式のgroups/outliner分離に対応しています。アニメーションは編集可能なフレームへサンプリングします（基本補間はlinear/step、Catmull-Romは近似、Bezier/Molangは完全互換ではありません）。
- 外部参照テクスチャはAndroidでは読み込めない場合があります。テクスチャをBlockbenchファイルへ埋め込むと、オフラインでも表示しやすくなります。ボーンウェイトやモーフ等の完全対応は今後の対象です。
- glTFは編集可能なNode3D階層を読み込みますが、Skeleton3Dのボーンアニメーション編集にはまだ対応していません。
- 2ボーンIKは解析解に対応しています。関節長を保って目標へ追従しますが、可動域制約が有効な場合は目標からずれることがあります。CCD・FABRIKは従来どおり利用できます。
- `.tres` はGodot側のアニメーションルートや階層構造との整合が必要です。
- `user://` のファイルはアプリ専用領域に保存されます。外部共有は端末環境に依存します。

## Godot書き出し精度の自動診断（2026-11-19更新）

- 「ファイル ▾」→「Godotアニメーションを書き出す」で保存した後、GodotのResourceLoaderで同じ `.tres` を再読込します。
- タイムライン上の最大32点のキー時刻で**全関節のローカル位置・回転・拡縮**を比較し、関節トラックの不足・重複や保存データの姿勢差を検出します。
- 最大16点の**キー間**の誤差も別に計測します。位置1cm・回転0.5度・倍率0.01を超えた場合は、有限FPSでの補間差を警告します（キー間の完全一致は保証しません）。
- 「詳細機能 ▾」→「ベイク」には、直近書き出し時の再読込検査・最大差・警告が表示されます。書き出し成功と照合成功は区別します。検査後も編集時刻を維持します。
- 出力トラックの座標は**Motion Studioの現在の親子階層を基準としたローカル値**です。ゲームのAnimationPlayerのルート・階層・関節名が違う場合は別途Godot内での動作確認が必要です。
- GitHub Actionsの `tests/test_export_audit.gd` で実ファイルの再読込、誤差測定、キー破損／トラック欠落検知を回帰テストします。Android実機の表示・タップ精度は未検証です。

## ファイル

- `Main.tscn` / `scripts/Main.gd`: 日本語UI、プレビュー、入力、各編集モード
