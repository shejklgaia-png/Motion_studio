# Motion Studio（開発試作版 v0.1）

Android縦画面を第一に考えた、**日本語UIのモーション・IK・制約・接触検証一体型エディター**です。Godot 4.xで制作し、無料・オフライン利用を前提としています。PCのGodotエディターでも開けます。

> **状態:** 機能検証用の試作版です。すべての構想機能が実装済みではありません。Godot本体を使用した実行テスト・Android実機テストは未実施です。

## 現時点で用意した機能

- 3Dサンプル四脚モデル、部位タップ選択、カメラ回転・ズーム
- タイムライン再生、1フレーム送り、数値による部位ごとの位置・回転・スケールのキーフレーム編集
- IK（CCD、FABRIK、2ボーン相当の反復CCD）と目標位置・強度・適用区間
- 位置・回転・スケールの軸別上限/下限、適用区間、強度
- テストオブジェクト（箱・球・カプセル）の配置と物理接触センサーによる検出
- IK目標の残差、サンプル足先の床からの浮き／めり込み診断
- 自動保存、Undo/Redo、専用JSON形式の保存・復元
- Blockbench 4.x/5.x `.bbmodel`：グループ階層・ピボット・cube/自由形状mesh・UV・埋め込みPNGテクスチャの読み込み
- Blockbench内に保存された複数アニメーションの選択・再生・キーフレーム編集（位置／回転／スケール）
- glTF/GLBシーンの読み込み
- IK・制約を各フレームで焼き込んだ Godot Animation `.tres` 出力
- IK/FKを全関節の編集可能なキーフレームへ変換（30/60fps）、IK自動停止、元モーション復元、差分診断

## 起動方法

Godot 4.6（Standard）で本フォルダの `project.godot` を開き、メインシーンを実行してください。Android上ではGodot Android Editorでプロジェクトを開いて確認できます。実機配布用APKの生成にはAndroid出力テンプレートなどが必要です。

## .bbmodelファイルの読み込み（Android）
1. アプリ上部の「BB読込」を押します。
2. Androidのファイル選択画面で、端末に保存した `.bbmodel` を選択します。
3. 画面中央にモデルが表示されたら、「読込モーション」で保存済みアニメーションを選びます。
4. 「▶ 再生」でモーションを確認し、部位を選んで編集します。

読み込み後、簡単なBlockbench 5形式のモデルとアニメーションについて、GitHub ActionsのGodot 4.6テストを実施しています。すべてのBlockbenchプラグイン独自要素に対応しているわけではありません。

## IK/FKベイク（Godotでの軽量な再生）

1. 「IK」で目標位置・計算方法を設定し、モーションの動作を確認します。
2. 「モーション」タブの下部、または「出力」タブの「IK/FKベイク」を開きます。
3. 記録精度を30fps／60fpsから選び、「IK/FKをキーフレーム化」を押します。
4. FK・IK・制約の合成結果を全関節のローカル位置・回転・拡縮に変換します。変換後は現在のIKと制約を無効化し、キーフレームのみで再生します。
5. 「ベイク前に戻す」で元のキーフレーム・IK・制約設定を復元できます。保存したMotion Studioプロジェクトには元データのバックアップも含まれます。
6. 「出力」でGodotアニメーション（`.tres`）へ書き出せます。

**注意:** フラットな床など、固定条件で事前計算できる動作に適します。ベイク後のIKは停止しますが、衝突検出や地形変化に合わせた補正を自動でベイクする機能ではありません。IKの目標・制約の矛盾は変換前に修正してください。ベイク時に中間フレームを比較し、位置・回転の最大誤差を表示します。サンプル間の完全一致は保証されません。

大量のキーフレームでスマホが操作不能にならないよう、時間バー下のショートカットは一部だけを表示します。全フレームのデータは保持され、スライダーとフレーム送りで編集できます。

## Blockbenchを参考にしたワークスペース

公式資料：[Blockbench Overview & Tips](https://blockbench.net/wiki/guides/blockbench-overview-tips/) （Viewport、Outliner、Transform Gizmos、Animate Timelineの説明）。

- **上段:** ファイルメニュー、再生、補助操作。その直下に「階層・モーション・IK・制約・接触・診断・ベイク」のモードタブ。
- **中央:** 3Dビューポート。右下に回転・移動・視点移動のツール。ピンチズームとタップ部位選択ができます。
- **タイムライン:** BlockbenchのAnimateモードを参考に、選択部位の回転／位置／拡縮を3行に分離。黄色い菱形のキーフレーム、青い再生ヘッド、時間目盛りを表示します。各位置をタップして再生時刻を変えられます。従来のキー追加・削除・フレーム送り・時間スライダーも残しています。
- **階層（Outliner）:** Blockbenchのように関節・部位の親子関係をツリー表示。タップで選択、部位名検索、選択部位のモーション編集への移動に対応します。
- **編集プロパティ:** モーションを選択すると部位のX/Y/Z位置、回転、サイズを数値入力でき、IK、制約、接触、診断、ベイクにもアクセスできます。

Blockbenchそのものの複製ではありません。既存のMotion Studio機能を保持し、特にAndroid縦画面で操作が詰まらないよう階層とプロパティをタブ型にしています。編集可能なモデル頂点やペイント機能は本バージョンでは未実装のままです（新しい機能を実装したと誤認させないため）。

## 操作方法

1. 起動直後の四脚モデルで「モーション」から編集部位とキーフレームを選びます。
2. 「IK」でチェーンと目標位置を指定し、有効化するとプレビューへ反映されます。
3. 「制約」で移動・回転・伸縮の限界を指定できます。
4. 「接触」で障害物を配置し、接地状態を確認します。
5. 「診断」で原本姿勢とIK計算後を比較し、「書き出し」で保存／出力します。

### 注意事項

- Blockbench 5形式のgroups/outliner分離に対応しています。アニメーションは編集可能なフレームへサンプリングします（基本補間はlinear/step、Catmull-Romは近似、Bezier/Molangは完全互換ではありません）。
- 外部参照テクスチャはAndroidでは読み込めない場合があります。テクスチャをBlockbenchファイルへ埋め込むと、オフラインでも表示しやすくなります。ボーンウェイトやモーフ等の完全対応は今後の対象です。
- glTFは編集可能なNode3D階層を読み込みますが、Skeleton3Dのボーンアニメーション編集にはまだ対応していません。
- 現段階の「2ボーン」は厳密な解析解ではなく、CCD反復回数を増やした試作方式です。
- `.tres` はGodot側のアニメーションルートや階層構造との整合が必要です。
- `user://` のファイルはアプリ専用領域に保存されます。外部共有は端末環境に依存します。
